## 👾 About the Project

Welcome to my personal developer portfolio!

This website is more than just a collection of projects. It represents my learning journey, technical interests, experiments, and the things I enjoy building.

The portfolio combines a retro pixel-art RPG-inspired visual identity with a modern web experience. Its design takes inspiration from classic indie games, featuring dark environments, pixel typography, glowing elements, and interactive UI details.

The goal is to create an experience that feels like exploring a game while discovering my work as a developer.

## ✨ Features

- **Retro RPG-inspired design** — Pixel-art aesthetics, dark backgrounds, and atmospheric visual elements.
- **Personal introduction** — Learn about my background, interests, and journey.
- **Project showcase** — Explore my development projects, experiments, and hackathon work.
- **Skills overview** — Discover the technologies and areas I am learning.
- **Responsive interface** — Designed to work across desktop and mobile screens.
- **Motion and animations** — Interactive visual effects powered by modern frontend technologies.
- **Contact section** — A way to connect and collaborate.

## ⚙️ Run Locally

Want to explore or run this project on your own machine?

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/mohitsinghjadon07-png/portfolio.git
```

### 2. Navigate to the project directory

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

The production-ready files will be generated inside the `dist` directory.
